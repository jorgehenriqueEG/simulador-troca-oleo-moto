# simulador-troca-oleo-moto
## Descrição do Problema
Sistema para calcular quando a próxima troca de óleo da moto deve ocorrer com base na quilometragem atual e no limite do óleo.
## Requisitos
- Ler a quilometragem atual do odômetro.
- Ler a quilometragem da última troca.
- Considerar o limite do óleo (ex: 5000 km).
- Calcular a distância restante até a próxima troca.
## Exemplo de Uso
Entrada: odometro = 12000, ultima_troca = 9000, limite = 5000
Saída: Faltam 2000 km para a troca de óleo.
